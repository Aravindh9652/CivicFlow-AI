Slide 5 · Technical Architecture

On-Device NPU + Hybrid Cloud AI Engine

⚡ 1. Local On-Device NPU Model CivicHashNgram-128 executes locally on phone hardware (Snapdragon NPU). Performs N-gram lexical scoring and emergency triage in 0ms offline.
☁️ 2. Cloud Gemini Flash Layer When online, requests enrich via Gemini Flash for deep semantic reasoning, formal email formatting, and multimodal image inspection.
🛡️ 3. Resilient Fallback Contract If cloud network drops, system seamlessly falls back to the local NPU classifier without freezing or failing user requests.
// Hybrid Architecture Execution Flow
const local = classifyLocal(problem, city);
try {
const cloud = await runGemini(problem, city);
return mergeHybrid(local, cloud);
} catch (netErr) {
// Zero latency offline fallback
return local;
}
